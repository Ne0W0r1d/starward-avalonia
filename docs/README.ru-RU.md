# Starward-Avalonia

> **Starward** происходит от слогана Star Rail: May This Journey Lead Us **Starward** («Пусть это путешествие приведёт нас к звёздам»), который очень хорошо подходит в качестве названия приложения.


> [!WARNING]
> Этот проект — форк Starward. Он будет портирован на Avalonia и предназначен для пользователей Linux.


Starward-Avalonia — это сторонний лаунчер с открытым исходным кодом, созданный для устранения недостатков HoYoPlay (лаунчера miHoYo). Он поддерживает все PC-игры HoYoverse и нацелен на полную замену официального лаунчера на Linux PC и Steam Deck. Помимо базовых функций лаунчера, я добавляю дополнительные возможности исходя из личных потребностей, например:

- Запись игрового времени
- Переключение игровых аккаунтов
- Просмотр скриншотов игры
- Сохранение истории гачи

Многие другие функции ждут вас...


## Установка

Сначала ваше устройство должно соответствовать следующим требованиям:

- Дистрибутив Linux с возможностью установки .NET 10
- Установленный WebKit2GTK


Затем скачайте пакет для вашей архитектуры CPU со страницы [GitHub Release](https://github.com/Ne0W0r1d/Starward-avalonia/releases). Распакуйте его, затем установите или запустите и следуйте подсказкам.


## Разработка

Установите [.NET 10 SDK](https://dotnet.microsoft.com/download). Затем соберите и запустите проект из корня репозитория:

```bash
dotnet build Starward.Avalonia.slnx
dotnet run --project src/Starward.Avalonia
```

Для редактирования кода можно использовать VS Code / VSCodium (с расширением C#) или JetBrains Rider.
